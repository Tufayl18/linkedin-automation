# Claude Code Configuration & Agent Instructions

This project strictly follows the rules defined in [AGENTS.md](./AGENTS.md).

## Summary of Core Rules:
- **Tone & Accuracy:** Technical, humble, practical engineering experiences (labs, troubleshooting, unexpected behaviors). Never invent claims. Always specify environment (e.g. AlmaLinux 9).
- **Spacing:** Exactly 1 empty line between sections/paragraphs. No large blocks of space.
- **No Synthetic Dividers:** Never use `---` or `--------` in `post.md`.
- **Bold Key Points:** Bold important concepts, commands, and takeaways.
- **Bullets:** Use `•` for bullets (no hyphens `-`).
- **Length:** 150–250 words (1,000–1,600 characters).
- **Emojis & Hashtags:** Max 2–3 contextual emojis. No hashtags unless requested.
- **Images:** Use descriptive filenames in `images/` (e.g. `shadow-after-usermod.png`). Confirm/rename image names with user before publishing.
- **Publishing:** Never publish without explicit user approval. Always follow `DRAFT → READY → user approval → PUBLISHED`.
